HƯỚNG DẪN TEST FILE SET - DAVID HUNTER V4.39 MATRIX (7 PP chưa triển khai)
=====================================================================

1. EA dùng để test
   EA_DAVID_HUNTER_V4_39_MATRIX_RECONCILE_2 (repo EA-PRO). File SET này KHÔNG dùng cho V4.52.

2. Thiết lập Strategy Tester (tab Settings)
   - Expert       : EA_DAVID_HUNTER_V4_39_MATRIX_RECONCILE_2
   - Symbol       : XAUUSD của sàn đang dùng (XAUUSDc / XAUUSDm), chart M1
   - Date         : càng dài càng tốt, ít nhất 3-6 tháng (ví dụ 2026.01.01 -> 2026.09.28)
   - Delays       : Zero latency / No delay (BẮT BUỘC; nếu có trễ, EA tự dừng và ghi lỗi TESTER_DELAY)
   - Modelling    : Every tick based on real ticks
   - Deposit      : 1000 USD (tài khoản cent: 100000 USC). Lot cố định 0.02 như LAB V4.39
   - Tài khoản    : Hedging. Nếu Tester là Netting thì đặt InpMatrixLenhTester=false
   - Optimization : Disabled (EA tự quét lưới bên trong một lượt chạy)

3. Nạp file SET (tab Inputs)
   - Chuột phải -> Load -> chọn file .set.
   - Kiểm tra dòng InpLuoi<PP> hiện đủ chuỗi. Nếu bị cắt ở dấu "|", dán lại chuỗi ở mục 7.
   - Muốn có phần dữ liệu kiểm chứng: đặt InpMatrixTuNgayKiemChung vào khoảng 2-3 tháng cuối
     (ví dụ 2026.07.01). Để 0 thì EA chỉ thăm dò, chưa tách kiểm chứng.
   - Muốn test khắt khe như set live: đặt InpMatrixTruotGiaVao=0.3.

4. Nên chạy theo thứ tự (file KIEM_CHUNG: 24-54 bộ input, chạy nhanh)
   V439_KIEM_CHUNG_EMA.set   -> ứng viên = ví 1  (M1, EMA 12/34, lọc M15, cả 2 hướng, cả ngày)
   V439_KIEM_CHUNG_PIN.set   -> ứng viên = ví 1  (M1, râu/thân 3.4, quét 3 nến, cả ngày)
   V439_KIEM_CHUNG_LQ.set    -> ứng viên = ví 3  (M4, xuyên 0.7-2.0, phiên Âu)
   V439_KIEM_CHUNG_ICT.set   -> ứng viên = ví 3  (M1, bias M30, Disp 0.9, Unicorn, phiên Âu)
   V439_KIEM_CHUNG_SMC.set   -> ứng viên = ví 7  (M1, bias cấu trúc M15, chỉ BUY, phiên Âu)
   V439_KIEM_CHUNG_PVEMA.set -> ứng viên = ví 2  (M6, xu hướng M30, ADX 14, phiên Á)
   File LUOI_DAY_DU (384-864 bộ) giống hệt lưới nghiên cứu Python, chạy RẤT LÂU.
   Nên chạy "1 minute OHLC" trước để lọc, rồi chạy lại "Every tick based on real ticks" cho bộ tốt.
   MM không có ứng viên; chỉ có file LUOI_DAY_DU_MM để thử lại ở giai đoạn thị trường khác.

5. Xem kết quả
   File -> Open Data Folder -> lùi lên thư mục Terminal -> Common\Files\<InpMatrixThuMuc>\RUN_...\
   - xep_hang.csv : mọi ví (bộ input x hướng x phiên), cột net, winrate_pct, profit_factor,
                    dd_equity_pct, lenh_dong, holdout_net, danh_gia, input_da_doi (bộ input của ví).
                    Ví 0 = danh mục gộp; ví 1-12 = cấu hình gốc (ứng viên) theo hướng x phiên;
                    từ ví 13 là các bộ trong lưới.
   - ket_qua_thang.csv, lenh_mo_phong.csv, thong_tin_run.csv : chi tiết theo tháng / từng lệnh / lượt chạy.

6. Tiêu chí đạt (đề xuất)

   DD chấp nhận được, các bộ input lân cận cũng lãi (không phải 1 bộ lẻ loi).
